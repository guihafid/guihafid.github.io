Sincronizar entre o computador e o tablet

Os dados passam a morar num gist privado da sua conta do GitHub. Cada aparelho que receber a chave abaixo lê e grava no mesmo lugar. Faça isto uma vez em cada aparelho.

  1. Entre em github.com → foto do perfil → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).
  2. Dê um nome qualquer, marque só a caixinha gist e gere. Copie o código que aparece (começa com ghp_) — ele só aparece uma vez.
  3. Cole o código aqui embaixo e aperte Criar o gist. No outro aparelho, cole o mesmo código e o mesmo número do gist, e aperte Conectar.
